2.1 Tentukan "Business Question" Utama
Kita akan menggunakan skenario ini:
"Manajemen Superstore mengalami penurunan profitabilitas meskipun penjualan terus meningkat. Sebagai Data Analyst, saya diminta menganalisis data penjualan untuk menemukan penyebab penurunan margin dan memberikan rekomendasi strategis."

2.2 Pilih 5 Query Terbaik Anda
Dari 15 soal di Hari 4 dan 5, serta 5 soal di Hari 6, pilih 5 query yang paling menjawab skenario di atas. Saya sarankan 5 query ini:

Q1 (Hari 6): Health Check (Total Sales, Profit, Margin, AOV).

Q2 (Hari 6): Profitabilitas Sub-Kategori (menemukan bahwa Tables & Bookcases rugi).

Q3 (Hari 6): Analisis Diskon vs Profit (membuktikan diskon >30% bikin rugi).

Q5 (Hari 6): Tren Bulanan (melihat pola musiman).

Q4 (Hari 5): Top 10 Customer by Profit (untuk strategi retensi VIP).

2.3 Rapikan Query SQL
Buka DBeaver, lalu copy-paste kelima query tersebut ke dalam satu file baru di VS Code dengan nama portofolio_superstore.sql.
